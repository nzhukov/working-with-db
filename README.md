## Итерация 1: SQLite + FastAPI + инструмент для управления БД

__Критерий 1.1. Инструмент для работы с SQLite (максимум 3 балла)__

[ ] Выбран альтернативный инструмент для работы с SQLite (не phpLiteAdmin; должно быть веб-базированное решение, как вариант - [такое](https://github.com/coleifer/sqlite-web)); обоснован выбор в README (0,5 балла).

[ ] Инструмент добавлен как отдельный сервис в docker-compose.yml (0,5 балла).

[ ] Сервис корректно подключается к тому, где лежит data.sqlite, и имеет доступ на чтение/запись (1 балл).

[ ] Интерфейс инструмента доступен по фиксированному порту (например, 8080), из него видно содержимое БД и можно выполнять запросы (1 балл).

__Критерий 1.2. Настройка временной зоны (максимум 2 балла)__

[ ] В docker-compose.yml для сервиса FastAPI или SQLite (в зависимости от архитектуры) передана переменная окружения TZ=Europe/Moscow либо установлен пакет tzdata и сконфигурирована временная зона (1 балл).

[ ] Временные метки, записываемые приложением FastAPI в БД, соответствуют UTC+3 (проверяется запросом к БД через инструмент из п. 1.1) (1 балл).

__Критерий 1.3. Функциональность приложения (максимум 3 балла)__

[ ] Приложение FastAPI запускается в Docker и доступно по порту 8000 (0,5 балла).

[ ] Реализован эндпоинт для добавления данных в data.sqlite (например, POST-запрос) (1 балл).

[ ] Данные, добавленные через FastAPI, корректно отображаются в инструменте из п. 1.1 (1 балл).

[ ] Файл data.sqlite сохраняется в томе и не теряется при перезапуске контейнеров (0,5 балла).

### Специфические критерии по вариантам (максимум по 3 балла за каждый)

__Для MongoDB (Артемий и Михаил)__

[ ] Используется официальный образ mongo или mongo:latest.

[ ] В коде FastAPI используется драйвер pymongo или motor.

[ ] Данные сохраняются в коллекции MongoDB и доступны для чтения.

__Для PostgreSQL (Данил, Игорь)__

[ ] Используется официальный образ postgres или postgres:latest.

[ ] В коде FastAPI используется psycopg2 или asyncpg.

[ ] Схемы и таблицы создаются автоматически (например, через sqlalchemy.create_all()).

__Для MariaDB (Михаил, Линь Хаоюнь)__

[ ] Используется образ mariadb или mariadb:latest.

[ ] В коде FastAPI используется pymysql или mysql-connector-python.

[ ] Данные корректно записываются и читаются, структура таблиц соответствует требованиям.

__Для CouchDB (Андрей)__

[ ] Используется образ couchdb или couchdb:latest.

[ ] В коде FastAPI используется requests или couchdb-python для взаимодействия с БД.

[ ] Документы сохраняются в CouchDB и доступны через REST API CouchDB.

__Для MySQL (преподаватель)__

[ ] Используется образ mysql или mysql:latest.

[ ] В коде FastAPI используется pymysql или mysql-connector-python.

[ ] Данные корректно записываются и читаются, структура таблиц соответствует требованиям.

__Для ClickHouse (повышенная сложность)__

[ ] Используется образ clickhouse/clickhouse-server.

[ ] В коде FastAPI используется clickhouse-driver или HTTP-интерфейс.

[ ] Данные записываются в таблицу ClickHouse и доступны для запросов (включая агрегации, если применимо).
